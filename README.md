# Easy Adventure

`Easy Adventure` 是一个基于 `Forge 1.20.1` 的基地收纳模组。

你可以用一张卷轴绑定基地核心，把整座基地打包带走，再在别处重新展开。

## 环境要求

- Minecraft `1.20.1`
- Forge `47.4.18+`
- 需要客户端和服务端同时安装


- 卷轴中只保存轻量数据
  - 基地 UUID
  - 结构 UUID
  - 主人信息
  - 基地名称
  - 尺寸信息
  - 密码模式相关元数据
- 基地本体数据保存在世界存档中

默认存档文件位置：

- 单人：`saves/<世界名>/data/easyadventure_buildings.dat`
- 服务器：`<世界目录>/data/easyadventure_buildings.dat`


### 强烈建议

- 升级前先备份世界
- 不要在基地正在收纳或释放到一半的时候换版本
- 升级到新版本后，不建议再回退到旧版本
