# Easy Adventure

基地收纳模组：使用基地核心与卷轴打包建筑，并在其他位置释放。

此分支当前构建配置使用 NeoForge 21.1.1 和 Java 21，模组元信息声明支持 Minecraft 1.21.1。分支名称不代表构建配置已经完成对应版本的迁移。

## 构建

```bash
./gradlew build
```

Windows 使用 `gradlew.bat build`。开发环境可使用 `runClient` 或 `runServer`。
